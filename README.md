# 于涛的个人网站

这是一个按 MVP 思路持续迭代的个人网站，用于展示个人经历、AI 能力、项目案例与行业思考。

线上地址：[taoy91885.com](https://taoy91885.com/)

## 当前页面

- `index.html`：个人网站首页。
- `ai.html`：企业财务 AI 应用全景图。这个路径已经对外使用，后续优化时应保持可访问。
- `cash-flow-forecast.html`：基于大模型的企业现金流预测场景研究。

## 目录结构

```text
.
├─ index.html                         # 首页入口
├─ ai.html                            # 财务 AI 全景图入口
├─ cash-flow-forecast.html            # 企业现金流预测场景入口
├─ assets/
│  ├─ css/                           # 页面样式
│  ├─ data/                          # 结构化内容数据
│  ├─ js/                            # 交互与渲染逻辑
│  └─ images/                        # 网站图片资源
├─ docs/                              # 架构和迭代说明
└─ AGENTS.md                         # 与 Codex 协作时的项目约定
```

## 迭代原则

1. 优先交付用户能感知、能验证的小步优化。
2. 保持公开链接稳定，避免让已发给客户的页面失效。
3. 内容数据、页面样式和交互逻辑分开管理。
4. 当前保持无构建依赖的静态网站；只在需求明显超出静态站能力时再升级技术架构。

## 本地查看

在项目目录启动一个静态文件服务后，访问首页或 `ai.html`。与 Codex 协作时，直接说“预览当前网站”即可。

## 与 Codex 协作

可以直接用自然语言描述目标，例如：

- “把首页改成一个更专业的个人作品集。”
- “在财务全景图中增加一个案例详情。”
- “继续优化现金流预测页面的数据清单和分析逻辑。”
- “检查手机上的显示效果并优化。”
- “确认无误后提交到 GitHub 并发布。”

默认流程是：本地修改 → 验证 → 你确认后再提交、推送和发布。
